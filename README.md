## 🎯 Project Overview
Developed a computer vision application to automatically identify and classify recyclable items from user-uploaded photos. Designed to improve waste sorting accuracy and support environmental awareness initiatives.

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **AI/ML:** TensorFlow, Keras, Computer Vision
- **Database:** SQL (item tracking & historical data)
- **UI:** Web-based interface for public demonstration
- **Tools:** Git, GitHub, VS Code

## ✅ Key Features
- Automatic image recognition & multi-class recycling classification
- SQL-backed database for tracking scanned items & categories
- Clean, user-friendly interface for real-time testing
- Modular architecture ready for dataset expansion & model fine-tuning
